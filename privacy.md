## 2. Kurzfassung

Die App „TI Reservierungen“ ist ein Client für selbst betriebene TastyIgniter-Installationen.
Der Entwickler der App erhebt, speichert oder empfängt **keine** personenbezogenen Daten.
Die App enthält keine Werbung, kein Tracking, keine Analyse- oder Absturzberichts-Dienste und
keine Bibliotheken von Drittanbietern, die Daten übermitteln.

## 3. Welche Daten verarbeitet die App?

Die App verbindet sich ausschließlich mit dem TastyIgniter-Server, dessen Adresse Sie selbst
in der App eintragen. Dabei werden verarbeitet:

- **Zugangsdaten** (E-Mail/Benutzername und Passwort) zur Anmeldung an Ihrem Server. Das Passwort
  wird nur zur Anmeldung übertragen; gespeichert wird lediglich das vom Server ausgegebene
  Zugangs-Token.
- **Reservierungsdaten** (z. B. Name, Telefonnummer, E-Mail-Adresse von Gästen, Datum, Uhrzeit,
  Personenzahl, Anmerkungen), die von Ihrem Server abgerufen bzw. dorthin gesendet werden.

Diese Daten werden direkt zwischen Ihrem Gerät und dem von Ihnen gewählten Server ausgetauscht.
Sie gelangen zu keinem Zeitpunkt an den Entwickler der App.

**Verantwortlich für die Verarbeitung dieser Daten ist der Betreiber des jeweiligen
TastyIgniter-Servers** (in der Regel das Restaurant). Es gilt dessen Datenschutzerklärung.

## 4. Speicherung auf dem Gerät

Lokal auf dem Gerät gespeichert werden nur die Serveradresse, das Zugangs-Token und
App-Einstellungen (z. B. Standard-Standort). Diese Daten sind von Android-Backups
ausgeschlossen und werden beim Abmelden bzw. beim Deinstallieren der App gelöscht.

## 5. Benachrichtigungen

Benachrichtigungen über neue Reservierungen erzeugt die App selbst, indem sie in Abständen
Ihren Server abfragt. Es wird kein Push-Dienst eines Drittanbieters (z. B. Firebase Cloud
Messaging) verwendet.

## 6. Datenübertragung und Sicherheit

Die Verbindung zum Server sollte per HTTPS erfolgen. Bei unverschlüsselten Verbindungen (HTTP)
zeigt die App einen Warnhinweis an; diese sind nur für Tests im lokalen Netz gedacht.

## 7. Update-Prüfung (nur bei Installation außerhalb von Google Play)

Wurde die App nicht über Google Play installiert (z. B. als APK von GitHub), fragt sie beim
Start die öffentliche GitHub-API ab, ob eine neuere Version verfügbar ist. Dabei wird technisch
bedingt Ihre IP-Adresse an GitHub übermittelt; es gilt die Datenschutzerklärung von GitHub.
Bei Installation über Google Play findet diese Abfrage nicht statt.

## 8. Ihre Rechte

Da der Entwickler keine personenbezogenen Daten über Sie speichert, kann er keine Auskunft
erteilen und keine Daten löschen. Für Auskunft, Berichtigung oder Löschung von Daten, die auf
einem TastyIgniter-Server gespeichert sind, wenden Sie sich bitte an dessen Betreiber.

Unabhängig davon haben Sie das Recht, sich bei einer Datenschutz-Aufsichtsbehörde zu beschweren.

Diese Erklärung wird angepasst, wenn sich die Funktionsweise der App ändert. Es gilt die
